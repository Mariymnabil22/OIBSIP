#  Esh7enli – EV Charging Landing Page

##  Project Overview

**Esh7enli (اشحنلي)** is a modern and responsive landing page for a mobile electric vehicle charging service.

The idea is to provide a convenient charging solution where a charging vehicle can come directly to the customer's location and charge their electric vehicle.

##  Project Goal

The goal of this project is to create a modern, attractive, and responsive landing page that introduces the Esh7enli service and makes it easy for users to understand the service and take action.

---

##  Features

*  Modern EV charging service concept
*  Clear hero section with call-to-action
*  Fully responsive design
*  Service and charging information
*  Charging/tracking concept
*  Booking call-to-action
*  Modern electric/futuristic visual style
*  Smooth animations and interactive elements
*  High-quality visual content
