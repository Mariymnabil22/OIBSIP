#  Personal Portfolio – Mariym Nabil

##  Project Overview

This project is a personal portfolio website designed to showcase my skills, projects, education, certificates, and experience as a **Frontend Developer and UI/UX Designer**.

The portfolio provides a simple and professional way for visitors and potential employers to learn more about me and explore my work.

---

##  Project Goal

The goal of this project is to create a professional, responsive, and user-friendly portfolio website that presents my technical skills and projects in an organized and attractive way.

---

##  Features

*  Personal introduction
*  Skills section
*  UI/UX and Frontend projects
*  Education information
*  Certificates
*  Resume/CV section
*  Contact section
*  Responsive design
*  Modern and clean user interface
*  Links to projects and professional profiles

---

##  Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript**
* **Responsive Web Design**

1. Download or clone the repository.

3. Open `index.html` in your browser.

No additional installation or dependencies are required.
