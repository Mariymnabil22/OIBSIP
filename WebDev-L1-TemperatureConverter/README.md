#  Temperature Converter

##  Project Overview

This project is a simple and user-friendly **Temperature Converter** website that allows users to convert temperature values between different temperature units.

The project provides an easy-to-use interface where the user can enter a temperature value, select the required conversion, and view the result instantly.

---

##  Project Goal

The goal of this project is to practice using **HTML, CSS, and JavaScript** to build an interactive web application and handle user input and calculations dynamically.

---

##  Features

*  Convert temperature values
*  User input for temperature values
*  Easy temperature conversion
*  Instant calculation using JavaScript
*  Clean and simple user interface
*  Responsive design
*  Works on desktop and mobile devices
*  Input validation for incorrect or empty values

---

##  Technologies Used

* **HTML5** – Structure of the webpage
* **CSS3** – Styling and responsive design
* **JavaScript** – Temperature conversion logic and user interaction

##  How to Run the Project

1. Download or clone the repository.
2. Open the `Task 3-TemperatureConverter` folder.
3. Open `index.html` in your browser.
4. Enter a temperature value.
5. Select the desired conversion and view the result.

No additional installation or dependencies are required.
